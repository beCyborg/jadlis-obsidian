# Obsidian ставится за вечер, а настраивается полгода — и всё равно не так

Этот плагин переносит на твой Mac рабочий Obsidian целиком: приложение, папки хранилища,
конфигурацию `.obsidian` со всеми плагинами и темой, скиллы Obsidian для Claude Code
и `CLAUDE.md`, из которого агент понимает, куда класть заметки.

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
claude plugin install jadlis-obsidian@jadlis --config VAULT_PATH=~/Jadlis
```

Это второй шаг маршрута Jadlis. Первый — настройка самого Claude Code, третий — голос.

![Приложение, папки, плагины и тема, правила для агента собираются в готовое хранилище](docs/img/hero-jadlis-obsidian.webp)

Текстом: слева четыре куска — приложение, папки, плагины с темой и правила для агента, —
справа готовое хранилище, в котором твоя раскладка панелей остаётся твоей.

Это моё рабочее место, выложенное как есть, а не продукт: чем перестал пользоваться — убрал.

## Как это работает

![Проверка, приложение и папки, плагины и тема, правила для агента, проверка делом](docs/img/how-jadlis-obsidian.webp)

На входе — Mac и путь, по которому будет лежать хранилище.
Внутри — проверка печатает PASS/FAIL, дальше идут только недостающие части, а прежняя
конфигурация уходит в бэкап.
На выходе — хранилище, в котором агент знает, куда класть заметки.

Текстом: проверка → приложение и папки → плагины и тема → правила для агента → проверка делом.

Что приезжает на твой Mac:

| Что | Что именно |
|---|---|
| **Приложение** | Obsidian из Homebrew, если его ещё нет в `/Applications`. |
| **Подписка Sync** | ссылка и объяснение, зачем она; покупаешь сам, цена на странице. |
| **Папки хранилища** | `Входящие`, `Файлы`, `Знания`, `Система/Планы` — четыре штуки, без методологии. |
| **Настройки Obsidian** | `app.json`, `appearance.json`, `core-plugins.json`: новая заметка идёт в `Входящие`, вложение — в `Файлы`, режим по умолчанию — чтение. |
| **12 плагинов** | Style Settings (крутилки темы), Advanced Canvas (схемы), Daily notes calendar (календарь заметок дня), Folder notes (заметка-обложка папки), Periodic Notes (день, неделя, месяц, квартал), My SVGs (свои иконки), Iconic (иконки и цвета папок), Linter (автоформат при сохранении), Dragger (перетаскивание блоков), Sidebar Highlights (выделения в панели), Editing Toolbar (панель форматирования), Flexplorer (сортировка и скрытие в проводнике). |
| **Тема и сниппет** | тема Border с сохранёнными цветами плюс CSS-сниппет `hide-files`. |
| **Хоткеи** | связки владельца, включая ⌘⇧H для выделения; хоткеи неустановленных плагинов вычищены. |
| **CLI** | `obsidian-cli` из приложения и симлинк `~/bin/obsidian` — Claude читает и пишет заметки из терминала. |
| **Скиллы Obsidian** | бандл `obsidian@obsidian-skills` от kepano: `obsidian-cli`, `obsidian-markdown`, `obsidian-bases`, `json-canvas`. |
| **`CLAUDE.md` в хранилище** | что это за папка, куда что класть, конвенции Obsidian-разметки, кликабельные ссылки на заметки из терминала. |

Скилл ведёт по девяти шагам, по одному за реплику, и перед каждым говорит, что сделает.

1. **Проверка.** `scripts/probe.sh` печатает `ключ=PASS|FAIL|SKIP` по всем частям сборки;
   дальше идут только те, что `FAIL`.
2. **Что купить.** Sync, ссылка, зачем он. Ждать оплаты не надо.
3. **Приложение.** `brew install --cask obsidian`, если его нет.
4. **Папки и `CLAUDE.md`.** Четыре папки плюс `CLAUDE.md`, `.claude/rules/vault-cli.md`
   и `.claude/settings.json`. Файл уже есть и отличается — рядом ляжет `.jadlis-new`
   и покажется `diff`.
5. **Конфигурация `.obsidian`.** Сначала сухой прогон со списком файлов, потом вопрос,
   потом копирование с бэкапом прежней папки.
6. **Открыть хранилище и снять Restricted mode.** Запущенный Obsidian принимает папку
   через IPC, без кликов. Дальше CLI выключает Restricted mode и проверяет: 12 плагинов
   включены, тема Border, ошибок нет.
7. **Sync.** Вход в аккаунт — только из интерфейса Obsidian.
8. **Бандл и CLI.** `obsidian@obsidian-skills` и симлинк `~/bin/obsidian`.
9. **Проверка делом.** Claude создаёт заметку в `Входящие` через CLI и читает её обратно.

Настройки плагинов приезжают там, где внутри не было чужих путей. У четырёх плагинов пути
вычищены, у двух настройки не едут вовсе — плагин берёт свой дефолт. Разбор по каждому —
в `skills/obsidian/references/plugins.md`.

Пересобрать поставку из живой конфигурации можно скриптом `tools/export-obsidian.py`:
он читает `.obsidian`, вычищает пути и личные данные и падает с кодом 1, если что-то
просочилось.

## Установка и первый запуск

Нужен macOS с Homebrew — приложение ставится командой `brew install --cask obsidian`.
Ещё нужны установленный Claude Code и `jq` для проверок.

**а) Текст для вставки агенту.** Скопируй целиком в чат Claude Code:

```
Ты — установщик. Поставь на этот Mac плагин jadlis-obsidian из маркетплейса jadlis.
Ключей и секретов этому плагину не нужно.
Сначала спроси меня, где будет папка хранилища, и подставь её вместо ~/Jadlis
во второй команде.
Выполни ровно эти команды, дословно, ничего не сокращая:
1. claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
2. claude plugin install jadlis-obsidian@jadlis --config VAULT_PATH=~/Jadlis
3. claude plugin list — покажи мне строку про jadlis-obsidian и его версию.
Потом скажи мне одной строкой: перезапусти Claude Code и напиши /obsidian.
Перед каждой командой покажи её мне целиком и дождись «да».
```

**б) Команды руками.**

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
claude plugin install jadlis-obsidian@jadlis --config VAULT_PATH=~/Jadlis
claude plugin list
```

Первая команда ничего не ставит — она добавляет маркетплейс. Ставит только вторая, и снимается
она одной строкой: `claude plugin uninstall jadlis-obsidian@jadlis --keep-data`. Путь хранилища
задаётся при установке через `VAULT_PATH`; не задал — берётся `~/Jadlis`.

**в) Короткая команда.** Перезапусти Claude Code и набери:

```
/obsidian
/obsidian статус
```

Не находится — сверь имя строкой `claude plugin list`. `/obsidian` и полная форма
`/jadlis-obsidian:obsidian` — одно и то же; `статус` только показывает, что уже настроено,
и ничего не меняет.

## Границы, стоимость, обновление

**Чего не трогает.** `workspace.json` и `workspace-mobile.json` — твои вкладки и раскладка
панелей остаются твоими. Существующие `CLAUDE.md`, `.claude/settings.json` и `.obsidian`
не перезаписываются без прямого «да»; прежняя конфигурация уходит в датированный бэкап рядом
с хранилищем. Заметки не читаются и никуда не отправляются. Подписка не оформляется за тебя.
Из моей конфигурации сюда не поехали закладки, граф, данные Sync и Publish, папка иконок
и настройки плагинов, внутри которых были пути к моим заметкам.

**Что стоит денег.** Только **Obsidian Sync** (<https://obsidian.md/sync>): заметки на телефоне
и бэкап с историей версий. Само приложение бесплатное, всё остальное в этом плагине — тоже.
Без Sync все девять шагов проходят до конца, заметки просто останутся на одной машине.
Семантического поиска по заметкам здесь нет — он живёт отдельно и в эту поставку не входит.

**Порядок расхода токенов.** Прогон лёгкий: субагентов и фан-аутов нет, вся работа — это
шелл-скрипты и вопросы человеку. Дороже прочего обходится разбор `diff` при столкновении
с уже существующим `CLAUDE.md`.

**Проверено там, где я работаю:** мой Mac, моя подписка, Obsidian 1.13.7. Только macOS: сборка
опирается на Homebrew и на приложение в `/Applications`, других систем я не проверял.

**Условия использования.** Лицензии нет: все права сохранены за автором. Читать и
пользоваться лично можно. Коммерческое использование, переиздание и включение в свои
продукты — по договорённости со мной.

**Сторонний код.** `assets/obsidian/plugins/` и `assets/obsidian/themes/` — неизменённые
сборки community-плагинов Obsidian и темы Border. Они остаются под своими лицензиями и за
своими авторами: Advanced Canvas (Developer-Mike), Daily notes calendar (bartkessels),
Dragger (Ariestar), Editing Toolbar (Cuman), Flexplorer (kh4f), Folder notes (Lost Paul),
Iconic (Holo), My SVGs (Omar Badawy), Linter (Victor Tao), Style Settings (mgmeyers),
Periodic Notes (Liam Cain), Sidebar Highlights (trevware), тема Border (Akifyss).
Лицензия и адрес репозитория каждого — в его `manifest.json`; файлы лицензий едут вместе
со сборкой, если автор кладёт их в поставку. Бандл скиллов `obsidian-skills` ставится
из маркетплейса kepano и живёт по своим правилам.

**Обновление.** У стороннего маркетплейса авто-обновление на твоей стороне выключено: пока не
запустишь первую команду, у тебя остаётся та версия, которую ты поставил.

```
claude plugin marketplace update jadlis
claude plugin update jadlis-obsidian@jadlis
claude plugin list
```

Переустановка, если что-то встало криво:

```
claude plugin uninstall jadlis-obsidian@jadlis --keep-data && claude plugin install jadlis-obsidian@jadlis
```
