## Какие настройки плагинов едут, а какие нет

`data.json` — это сохранённые настройки плагина. Едет он не у всех: у некоторых внутри
пути к папкам владельца.

| Плагин | `data.json` | Почему |
|---|---|---|
| `obsidian-style-settings` | как есть | только цвета и переменные темы |
| `obsidian-linter` | как есть | правила форматирования, списки исключений пустые |
| `editing-toolbar` | как есть | состав панели и цвета |
| `dragger` | как есть | внешний вид ручек перетаскивания |
| `folder-notes` | как есть | флаги поведения, `templatePath` пустой |
| `periodic-notes` | без `folder`/`template` | там были папки методологии владельца |
| `daily-note-calendar` | без `folder`/`templateFile` | то же самое |
| `my-svgs` | без `iconsFolder` | путь к папке иконок владельца |
| `iconic` | без иконок и правил | ключи были путями заметок и папок владельца |
| `advanced-canvas` | нет | у владельца не было своего `data.json` |
| `sidebar-highlights` | не едет | внутри пути заметок |
| `flexplorer` | не едет | внутри тысячи путей файлов владельца |

Настройка, которая не приехала, не ломает плагин: он берёт свой дефолт.

## Что не едет вообще

`workspace.json` и `workspace-mobile.json` (вкладки и панели), `bookmarks.json`,
`graph.json`, `publish.json`, данные Sync, папка иконок `my-svgs`, резервные копии
плагинов. Плагины, которых нет в `community-plugins.json`, тоже не едут — вместе
с их хоткеями.

## Как пересобрать поставку

Скрипт `tools/export-obsidian.py` читает живой `.obsidian` и заново собирает
`assets/obsidian`, вычищая пути и личные данные. Он же в конце проверяет результат
и падает с кодом 1, если что-то личное просочилось.

```
python3 tools/export-obsidian.py --source ~/Jadlis/.obsidian
```

Сборки плагинов и темы едут байт в байт, с одним исключением: в баннер-комментарий
сторонней библиотеки, где стоит почта её автора, дописывается пометка `privacy-ok` —
иначе на ней спотыкается сканер приватности репозитория. Код, копирайт и текст лицензии
при этом не трогаются; сейчас такая пометка есть в двух строках `editing-toolbar/main.js`
(баннер Sortable). Файл `LICENSE` автора, если он лежит в поставке плагина, едет рядом
со сборкой.
