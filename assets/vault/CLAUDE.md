# Vault

## Что это

Эта папка — Obsidian vault: личная база заметок, а не программный проект.
Кода, билдов и тестов здесь нет — только заметки, canvas-файлы и вложения.

## Куда что класть

| Папка | Что в ней |
|---|---|
| `Входящие/` | всё новое падает сюда: мысли, ссылки, черновики |
| `Знания/` | то, что уже разобрано и к чему возвращаешься |
| `Файлы/` | вложения — картинки, PDF, svg |
| `Система/Планы/` | планы Claude Code (режим плана пишет их сюда) |

Новая заметка без явного адреса → `Входящие/`. Вложение → `Файлы/`
(эти два пути заданы в настройках Obsidian, не меняй их врозь).

## Конвенции заметок

- Формат — Obsidian-flavored Markdown, не обычный markdown:
  wikilinks `[[Заметка]]`, embeds `![[Заметка]]`, callouts `> [!note]`,
  YAML frontmatter (properties) в начале файла.
- Wikilinks ставить только на реально существующие заметки — unresolved links не создавать.
- SVG вставляется файлом: `![[схема.svg|300]]`. Инлайновый `<svg>`/HTML Obsidian рисует сам,
  но внутри transclusion `![[заметка]]` инлайновый `<svg>` покажется исходником —
  сложную графику держать отдельным `.svg` в `Файлы/`.
- Перед созданием заметки проверить, нет ли такой же: `command grep -rIl "<ключевое слово>" .`

## Ссылка на заметку в терминале

Упоминаешь заметку в ответе — дай кликабельную ссылку Obsidian URI
`[<имя без .md>](<URI>)`: текст читаемый, URL полностью percent-encoded
(чистый ASCII надёжно ловится по Cmd+клику в iTerm2/tmux).
Путь — от корня vault, без `.md`; заголовок внутри заметки → `#Заголовок`
дописать к пути ДО кодирования. `[[wikilinks]]` внутри заметок не трогать —
URI нужны только для вывода в терминал.

```
python3 -c "import urllib.parse,sys;print('obsidian://open?vault=<имя vault>&file='+urllib.parse.quote(sys.argv[1]))" "<путь от корня vault>"
```

## Инструменты Obsidian

Vault обслуживает плагин Obsidian Skills (obsidian-cli, obsidian-markdown,
obsidian-bases, json-canvas): чтение и создание заметок, дневные заметки,
properties, backlinks, `.base` и `.canvas` из терминала.

Особенности CLI и ловушки поиска (тихое ложное «ничего не найдено») —
`.claude/rules/vault-cli.md`, файл загружается сам.
